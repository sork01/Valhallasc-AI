# Kill-time report

Generated by `bash scripts/ttk-parallel.sh` from five isolated in-memory class runs.
Baseline gear: green (uncommon) progression set of the level, no refinement or set bonus (decided 2026-10-15).
Each cell is **median kill seconds / damage per landed monster hit**. `FAIL` means at least one seed did not kill the target; failed seeds count at the rotation cap.
