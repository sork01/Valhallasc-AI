# Hierloom raid gear

Owner request, 2026-10-26, Beta 1.25.0. Rarity is spelled **Hierloom** (`hierloom`), with golden icons, borders, loot pillars and roll cards.

The Chained Forge's ten bosses each have an additional **10% base chance for one random piece**: Dawnkeeper Ring, Everember Ring, Legacy of the Forge (necklace), or Mantle of Generations (cloak). Selection is equally likely. Existing guaranteed Chainforged orange tables are unchanged. The rebirth drop multiplier applies, as for every other drop: 10%, 20%, 30%, 40%, 50%. Raid packs and other bosses never roll these items. The ordinary raid Need/Greed/Pass rules distribute them among humans; hired fighters cannot take them.

All four are class-neutral and wearable from level 1. Each equipped slot grants **+100% XP**, added to the rebirth XP percentage. Four pieces give 500 XP for a base 100 XP; capped rebirth plus all four gives 550 XP. Spare/banked copies give nothing. Kill XP, shared-party XP and quest XP use the same authoritative boost. [Rested](rested.md) adds a further +200% of base XP while its reserve lasts, so the combined maximum is 750 XP per base 100 XP. Two copies of either ring may occupy the two accessory slots; each slot still needs an owned copy.

Each piece grants strength, agility and intellect equal to the wearer's current level, and stamina equal to twice that level. There is no flat attack/defense or accuracy/dodge bonus. The server derives attributes when read; saved copies retain their level-1 budget. The client uses that same per-level catalog budget for tooltips and comparisons. Inspect uses the inspected player's level. Rebirth immediately returns the attributes to level-1 values while leaving these pieces equipped. Transferring one uses the new wearer's level.

They never wear, break or need repairs, and cannot merge or refine. They do not count towards dungeon set bonuses. They follow the normal class-neutral trade/bank/sale rules, with a valuable-item confirmation before sale. Existing worn sprite variants are reused; golden glyphs use the established inventory SVG system, with distinct ring gems. No new sprite atlas is required.

`scripts/hierloom_catalog.py` is the idempotent catalog overlay, run last by `sync-world.cjs`. `gear_levels.py` preserves the authored source and `cloak_catalog.py` preserves its cloak; `set_bonuses.py` excludes this non-set source. Runtime rules and deterministic boundary checks live in `server/src/items/hierlooms.rs`; bounded real loot/XP/Inspect checks live in `server/src/world/hierloom_tests.rs`. `tests/hierloom-ui.cjs` checks golden presentation, live scaling, death and the real rebirth confirmation on a private server.
